# 3D-solar-system

Projeto básico com Next.js, React, TypeScript e Tailwind CSS. A página inicial está vazia.

```bash
npm install
npm run dev
```

Abra http://localhost:3000. Edite `src/app/page.tsx` para começar.

```bash
npm run build  # Build de produção
npm start      # Executa o build de produção
npm run lint   # ESLint
```
